# Java Coursework – ShopGadget Application

This project is a Java Swing application designed to manage different types of gadgets, including Mobiles and MP3 players. It demonstrates object‑oriented programming principles such as inheritance, encapsulation, and polymorphism, while also using ArrayLists to store and manage gadget objects.

## Features
- Add Mobile and MP3 gadgets through a GUI
- Display all stored gadgets
- Make calls (Mobile)
- Download music (MP3)
- Input validation to prevent runtime errors
- Demonstrates event handling and GUI interaction

## Technologies Used
- Java
- Java Swing
- BlueJ

## Files Included
- Gadget.java
- Mobile.java
- MP3.java
- ShopGadget.java

## Purpose
This repository contains my coursework for demonstrating Java programming skills, GUI development, and object‑oriented design.
